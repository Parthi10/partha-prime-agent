# Protecto Prime Agent V1 Architecture

## Scope

Version 1 focuses on the internal platform foundation for a single-organization PR review workflow. The initial implementation includes the FastAPI API, typed configuration, async PostgreSQL access, Redis health checks, structured logging, Alembic migration support, Docker Compose deployment, and the initial domain models required for later workflow automation.

## Components

- API service for health endpoints and future workflow entry points
- PostgreSQL for durable storage of repository, PR, workflow, scan, finding, report, notification, and audit entities
- Redis for service health checks and future job orchestration
- Docker Compose for local orchestration of the API, PostgreSQL, and Redis

## Design Notes

- The implementation uses UUID primary keys and UTC timestamps.
- The initial models include provider identifiers, commit SHAs, correlation IDs, and audit trail fields.
- The platform avoids storing webhook secrets or credentials in database models.
- The architecture is intentionally limited to Milestone 1 and excludes Bitbucket integration, scanner execution, policy enforcement, and email delivery.
